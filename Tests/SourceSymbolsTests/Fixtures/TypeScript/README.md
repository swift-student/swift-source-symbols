# TypeScript / TSX declaration corpus

Fixtures are independently authored syntax inputs; JSON expectations specify
snapshot-bound, zero-based, half-open UTF-8 offsets from the literal source bytes.
They are not snapshots generated by the extractor. Do not normalize the intentional
CRLF fixture or combining-character spellings. All diagnostics and declaration
ordering are asserted through the shared backend contract.

| Fixture | Coverage |
| --- | --- |
| `declarations.ts` + JSON | Exported dotted namespace, interfaces, aliases, enum members, decorated abstract class, fields/private names, constructors, overloads, accessors, ambient module, grouped bindings |
| `signatures.ts` | Generics/constraints/defaults, optional/rest/destructured/untyped parameters, predicates/assertions, generators, direct/parenthesized arrows and named function expressions; explicit `this` has no signature |
| `scopes.ts` | Destructuring bindings, object properties/methods, callable and class initializer scopes, anonymous bodies, duplicate locals, loops, omitted references/imports/nested type members |
| `headers.ts` | Export/default/declare/decorator syntax, interior comments, default-expression braces, grouped closure headers, static blocks, quoted/private/numeric and omitted computed names |
| `component.tsx` + JSON | JSX elements/fragments/attributes/text, generic arrow disambiguation, nested executable expressions, exported component bindings |
| `unicode-lf.ts`, `unicode-crlf.ts` + JSON | Non-ASCII namespace and identifiers, decomposed accents, non-BMP defaults, exact newline bytes, header/identifier position conversion |
| `recovery.ts` + JSON | Body errors preserving metadata; broken annotations and missing parentheses invalidating headers/signatures; diagnostic order and zero-width offsets |
| `wrapper-recovery.ts` | Malformed export wrapper invalidates callable metadata; missing body closer preserves a sound header |
| `dialect.ts` | Angle-bracket assertion parses in TypeScript but is JSX recovery in TSX |
| `incomplete.ts` + JSON | Unterminated class/method collapses to `ERROR`; only the local binding survives without inferred scopes |

Integration tests additionally cover empty input, embedded NULs without truncation,
explicit language rejection, and simultaneous reuse of one extractor for both
grammars. These fixtures include syntactically extractable examples whose semantics
need not type-check; no TypeScript compiler validation is claimed.
